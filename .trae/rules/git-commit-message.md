# 提交信息生成规则（必须严格遵守）

## 1. 语言
- 所有文字（包括标题、描述、改动点）**必须使用中文**，禁止使用英文。

## 2. 标题（Subject）格式
- 格式：`<类型>(<范围>): <Emoji> <中文短描述>`
- 冒号为英文冒号，后面跟一个空格。
- Emoji 紧跟在冒号空格之后。

### 类型与 Emoji 对应表（必须严格匹配）
| 类型 | 说明 | Emoji |
|------|------|-------|
| feat | 新功能 | ✨ |
| fix  | 修复 Bug | 🐛 |
| docs | 文档变更 | 📝 |
| style| 代码格式/样式（不影响逻辑） | 💄 |
| refactor | 代码重构 | ♻️ |
| perf | 性能优化 | ⚡️ |
| test | 测试相关 | ✅ |
| chore | 构建/工具/依赖 | 🔧 |
| ci   | CI 配置 | 👷 |

**正确标题示例**：
- `feat(登录): ✨ 增加短信验证码登录`
- `fix(支付): 🐛 修复订单金额计算精度丢失`

## 3. 详细描述（Body）要求
- 标题和 body 之间**必须空一行**。
- body 内容必须使用中文。
- body 以**编号列表**形式列出本次提交的具体改动点，例如：
  - 1. 新增登录页面的验证码登录功能
  - 2. 修复支付页面的金额计算精度丢失问题
  - 3. 优化登录页面的性能
